# Privacy and AI Use

SOPPilot AI is a public portfolio demo and process documentation assistant. It is designed for fictional, sample, or non-sensitive process documentation.

## User Data Guidance

Do not enter sensitive, confidential, regulated, or private information into the public demo.

Avoid entering:

- Internal company secrets
- Proprietary procedures that should not be public
- Customer personally identifiable information
- Employee confidential records
- Medical, legal, safety-critical, or regulated process details
- Passwords, API keys, or credentials

## AI Processing

When an OpenAI token is configured, selected user inputs may be sent to the AI provider to improve the SOP package.

The app is built so that:

- Rules-based documentation logic is the source of truth
- AI only improves wording, clarity, and structure
- AI should not invent policies, standards, compliance requirements, or regulated procedures
- AI failure falls back silently to rules-based output
- The app does not intentionally store user-submitted data

## Input Limits

The AI helper trims long prompts before AI enhancement to improve reliability and control cost.

Sensitive or proprietary processes should be generalized before being entered into the public demo.

## Public Demo Note

All built-in sample names, companies, and scenarios are fictional and created for portfolio demonstration purposes.
